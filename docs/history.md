## Pilot results (Feb–Apr 2026)

| Metric | Result |
|---|---|
| Would keep using it if permanent | 100% |
| Use 2–5 times per day | 80% |
| Save 5–20 min per query | 60% (others < 5 min) |
| Confidence in information | 4.2 / 5 |
| Usefulness | 4.6 / 5 |
| Fewer "How do I…" questions to support | 60% agree, 40% neutral, 0% disagree |
| Most valued feature | Clear step-by-step guidance |

Working ROI model: 200 users × 1 query per day × 15 min ≈ 50 h/day, or about 1,000 h/month.

Adoption at the V2 workshop (May 2026): 86 unique users, with 1,000+ conversations expected within 1–2 months.
